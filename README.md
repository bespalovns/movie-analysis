# Анализ фильмов TMDB

Индивидуальная работа по дисциплине «Системы больших данных».

Беспалов Николай Сергеевич, ИСТZ-3401

В проекте выполнены очистка и нормализация данных о фильмах,
построены 10 интерактивных графиков и сформулированы выводы.
Рассмотрены жанры, зрительские оценки, продолжительность,
бюджеты и кассовые сборы.

**Технологии:** Python, Pandas, NumPy, Bokeh.

## Просмотр

Скачайте проект и откройте `output/index.html` в браузере.
Для просмотра готовой страницы Python и интернет не нужны.

## Запуск скрипта

1. Установите Python и зависимости:
   `python -m pip install -r requirements.txt`
2. Поместите исходные CSV-файлы в папку `data/raw`.
3. Выполните:
   `python build_report.py`

Страница и подготовленные данные появятся в папке `output`.

## Источник данных

[TMDB 5000 Movie Dataset — Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata)

Использованы файлы `tmdb_5000_movies.csv` и `tmdb_5000_credits.csv`.
Выводы относятся к этому набору данных, а не ко всем фильмам.
